=================================================================
WIREFRAMES / MOCK-UPS - SPORTSCHOOL "DE KAST"
Fase 1 - Werkproces B1-K1-W2 "Ontwerpt software"
=================================================================

De applicatie is een console-applicatie (CLI) op een kiosk-pc bij de
ingang. De wireframes hieronder tonen elk scherm zoals het in de
terminal verschijnt. Tekst tussen < > is invoer van de gebruiker.

-----------------------------------------------------------------
SCHERMSTROOM
-----------------------------------------------------------------

                     +-------------+
                     |  [S0]       |
                     |  Hoofdmenu  |
                     +------+------+
               1 /          |          \ 0
                /           | 2         \
   +-----------v--+   +-----v--------+   +----------+
   | [S1] Login   |   | [M1] Login   |   | Afsluiten|
   | sporter      |   | medewerker   |   +----------+
   +------+-------+   +------+-------+
          | ok               | ok (fout -> terug naar S0)
   +------v-------+   +------v-------+
   | [S2]         |   | [M2]         |
   | Sportermenu  |   | Medewerker-  |
   +--+--+--+--+--+   | menu         |
      |  |  |  |      +--+--+--+--+--+
      |  |  |  |         |  |  |  |
      |  |  |  +-> [S6] Opzeggen      [M3] Zoeken / status
      |  |  +----> [S5] Coach-afspraak [M4] Abonnement wijzigen
      |  +-------> [S4] Cursus in-/uitschrijven
      +----------> [S3] Inchecken     [M5] Logs

Na elke actie keert de gebruiker terug naar zijn eigen menu (S2 of M2).
Met 0 logt de gebruiker uit en komt hij terug in het hoofdmenu (S0).

-----------------------------------------------------------------
ONTWERPKEUZES VOOR USABILITY
-----------------------------------------------------------------
  - Elk menu is genummerd en 0 betekent altijd "terug/uitloggen".
  - Waar een naam ingevoerd moet worden (cursus, coach), toont het
    systeem eerst de geldige keuzes. De invoer is hoofdletterongevoelig.
  - Onomkeerbare acties (opzeggen, inschrijven) vragen eerst ja/nee.
  - Elke melding noemt de sporter en de reden, in gewoon Nederlands.
  - De medewerker ziet de huidige situatie vóór hij/zij iets wijzigt.
